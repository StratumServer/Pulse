P U L S E
Wake up, admin. Your server has a pulse.

A server-side observability mod for Vintage Story. Drop the zip in Mods/, start the server, and http://127.0.0.1:9464/metrics answers with everything Prometheus and Grafana need.

v0.1.0  VS 1.22.x  SERVER SIDE  OPEN SOURCE  ZERO DEPENDENCIES

 

> what_you_get_to_graph
  • tick health: tick rate, tick time as a histogram (p95 and p99 are yours), the configured budget to read saturation against, and the engine's own tick busy time: how much of each tick was actual work. That is the /stats number, and it shows load climbing long before TPS ever drops.
  • players: online count, ping average and max, deaths.
  • world: entities loaded plus the ten most numerous types, chunks loaded, worldgen queue depth, columns generated.
  • network: TCP and UDP, live rates and running totals.
  • autosave pauses: how often the server suspended and for how long. That is the freeze players actually feel.
  • log health: warnings, errors and fatals as counters, plus four engine warnings worth alerting on: tick overload, high memory, suspend timeout, autosave disk contention.
  • the .NET runtime: GC collections and pause time, heap, working set, CPU, thread pool.

Real output. No agent, no database, no account. The text format is the contract: Prometheus scrapes it, Grafana graphs it, and game panels can read it directly; the first panel integration was built that way in an afternoon.

 

> three_ways_to_consume

[1] scrape. Point a Prometheus at the endpoint; the repository's contrib/grafana folder holds a fully provisioned dashboard that comes up with two docker commands.

[2] panel. Game panels skip Prometheus and read /metrics directly, on the same host, no auth exposure.

[3] push. A second optional mod, pulseotlp (on the GitHub releases page), pushes the same metrics over OTLP to whatever you already run: an OpenTelemetry collector, Grafana Cloud, Datadog and the rest. Its dependencies travel in its own zip; the base mod stays clean.

 

> built_careful

The endpoint binds loopback by default: a game server is a public host and metrics carry no authentication, so widening the bind is a decision you make on purpose, ideally behind a reverse proxy. The base mod is a single dll with nothing bundled, so there is nothing to collide with other mods. Metrics never touch live world state off the main thread, and a failed port bind logs an error while the game server carries on.

Built from a survey of the 1.22 server internals rather than guesswork. Every release ships from CI with 126 unit tests, 20 scenarios that boot a real headless server, and a mutation check. Works on the vanilla dedicated server; the Stratum and Lithos forks keep the modding API intact, so the same zip loads there too.
